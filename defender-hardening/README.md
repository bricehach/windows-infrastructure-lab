# Microsoft Defender & hardening Windows

Cette section regroupera les mesures de durcissement Windows et la configuration de Microsoft Defender dans une logique contrôlée et documentée.

## Sujets prévus

- Microsoft Defender Antivirus
- Microsoft Defender Firewall
- Protection cloud et réputation
- Attack Surface Reduction
- Controlled Folder Access
- Paramètres PowerShell utiles
- GPO de sécurité
- Réduction de la surface d'attaque
- Services et fonctions optionnelles
- Vérification après durcissement
- Compatibilité et effets secondaires
- Procédures de retour arrière

## Principe

Le hardening doit réduire le risque sans casser inutilement l'usage légitime du poste. Chaque modification doit être contextualisée, testée et réversible lorsque possible.

Matière disponible — à développer progressivement en guides, références et check-lists.
