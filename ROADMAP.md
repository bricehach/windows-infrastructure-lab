# Roadmap — Windows Infrastructure Lab

Ce document organise la transformation progressive des sujets déjà travaillés en ressources GitHub utiles, vérifiables et réutilisables.

## Priorités de publication

1. Installation propre de Windows 11 Pro
2. Compte administrateur local et post-installation
3. Confidentialité, télémétrie et transparence des données
4. Winget et maintenance applicative
5. Réparation du démarrage Windows
6. BSOD / Bug Check / dumps
7. Pilotes et BIOS
8. Journaux Windows et Event ID de stabilité
9. Microsoft Defender, GPO et hardening
10. Troubleshooting transversal

## Règle documentaire

Chaque ressource doit idéalement suivre cette logique :

```text
Contexte
   ↓
Objectif
   ↓
Prérequis
   ↓
Comprendre
   ↓
Procédure
   ↓
Vérification
   ↓
Risques / limites
   ↓
Retour arrière
   ↓
Troubleshooting
   ↓
À retenir
```

## Statuts

- **Prévu** : sujet identifié
- **En rédaction** : contenu en cours de structuration
- **Publié** : ressource disponible dans le repository
- **À revoir** : contenu à actualiser ou à compléter

## Objectif à moyen terme

Construire une base Windows qui puisse servir à la fois de :

- support d'apprentissage ;
- référence rapide ;
- guide de dépannage ;
- documentation de sécurité ;
- preuve technique dans le portfolio professionnel.
