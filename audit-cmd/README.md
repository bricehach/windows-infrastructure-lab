# Audit et maintenance Windows avec CMD

Cette section regroupe un cours pédagogique pour auditer, diagnostiquer et réparer des postes Windows 10 et Windows 11 avec l’invite de commandes.

## Ressources

- [Cours complet — Markdown](Audit_PC_Windows_CMD_W10_W11.md) : version consultable et modifiable directement sur GitHub.
- [Cours complet — Word](Audit_PC_Windows_CMD_W10_W11.docx) : version mise en page pour l’enseignement.

## Périmètre

- Commandes internes de `cmd.exe` et exécutables Windows.
- PowerShell exclu.
- Les commandes Windows 10 sont identifiées ; les différences Windows 11 sont signalées.
- Contrôles, collecte d’éléments, interprétation, réparations contrôlées, limites et risques.
- Aucune donnée issue d’un poste réel.

## Statut

Publié — vérifier l’aide locale et la documentation Microsoft correspondant à la version de Windows avant toute opération de maintenance.
