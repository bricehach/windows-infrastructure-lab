# Journaux Windows & Event ID

Cette section regroupera les ressources consacrées aux journaux Windows utiles à l'administration, au diagnostic et à la sécurité.

## Sujets prévus

- Event Viewer
- Journaux System, Application et Security
- Event ID liés aux arrêts et redémarrages
- Event ID 6008
- Event ID 1101
- Corrélation avec pilotes, BIOS et stabilité
- Filtrage et export des événements
- PowerShell pour interroger les logs
- Différence entre événement, symptôme et cause
- Construction d'une chronologie de diagnostic

## Statut

Matière disponible — à transformer en fiches de référence et labs de diagnostic.
