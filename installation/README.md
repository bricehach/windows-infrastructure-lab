# Installation et mise à niveau Windows

Cette section rassemble les notes de préparation, d’installation, de mise à niveau et de dépannage de Windows 10/11.

## Guide

- [Installation, mise à niveau et dépannage de Windows 10/11](guide-installation-mise-a-niveau-windows-10-11.md)

## Contenu

- Choisir entre mise à niveau, installation propre, récupération et déploiement
- Préparer l’appareil, les données, BitLocker et le média
- Vérifier l’éligibilité Windows 11, la langue et l’édition
- Diagnostiquer les échecs Setup avec SetupDiag et les journaux
- Utiliser Coreinfo comme vérification complémentaire
- Comprendre les limites d’un essai sur matériel non pris en charge
- Contrôler l’installation et documenter l’intervention

Le guide distingue Windows 10 comme système hérité et Windows 11 comme cible courante. Les commandes sont en CMD ; aucun script PowerShell ni scénario pédagogique n’est inclus.
